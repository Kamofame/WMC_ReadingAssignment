Marhba bikom f CheatSheet dyali dyal HTML

Hada spickzettel sah w mabsot l l-ibtidaiyin

1. Mafahim Asasiya (Grundbegriffe)

WWW (World Wide Web): Shabaka 3alamiya katsta3ml URL w HTTP bach tchof l-mawaqi3.

Web Server: Computer aw barnamaj kayxodi l-mohtawa w kayiftoho l n-nas.

Web Client: Bhal l-browser (Chrome, Firefox) lli kaystayn l-mohtawa mn l-server.

2. Wasa2if w Tags Mohemma (Basic Tags)

html - Kayakhla9 l-milaf dyal HTML

head - Kaykon fih l-ma3lomat l-barraniya bhal l-3onwan

title - Kaydir smiyat l-page f l-foq f l-browser

body - L-blasa lli kayban fiha kolchi l-mohtawa

h1 - 3onwan kbire w mhem

p - Paragraph aw sotora dyal l-ktaba 3adiya

strong - Kayrdd l-ktaba ghlidza

em - Kayrdd l-ktaba mayla

Bei HTML wird immer eine Branche geoefnet und mit einem / geschlossen
